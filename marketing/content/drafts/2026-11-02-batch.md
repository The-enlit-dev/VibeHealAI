### 2. Five checks before you keep an AI change
- Platform: X (thread, 6 posts)
- Pillar: Education
- Topic: Simple checks for beginners
- Target audience: Beginner vibe coders
- Suggested date: Tue 3 Nov 2026
- Draft copy:
  > 1/ Before you accept an AI change, pause for a minute. Five checks that help:
  >
  > 2/ Copy the project folder first. A zip file is enough.
  >
  > 3/ Look at which files changed. If the list is longer than you expected, ask why.
  >
  > 4/ Read the first line of the error, not only the last one. It often names the file.
  >
  > 5/ Run the build or the tests before you go on. A passing check is evidence, not a guarantee.
  >
  > 6/ Keep the version that worked. If the fix goes wrong, you can go back. BrixoAI is being built around these habits. It's planned, not released yet.
