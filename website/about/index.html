About

About the project

VibeHeal is a planned AI assistant for vibe coders: people who build apps, websites and software with AI tools. It aims to help with project understanding, debugging, integrations, automations and code safety. It is in early development and not available yet.

Why it exists

AI coding tools make it possible to build an app in an afternoon. The hard part is often everything around the code: understanding what changed, working out why something broke, keeping track of hosting, databases and design tools, and repeating the same chores. This project aims to help with that wider workflow, while your own AI tool keeps doing the coding.

What exists today

An early development foundation: a local backend, an integration platform and a read-only GitHub connection, tested by the developer with automated tests against a simulated GitHub API. Not a public release.

Planned next: Project understanding, debugging help, code safety and recovery, automations, scheduled automations, workflow management and more integrations.

Not decided yet: The release date, pricing, the website domain and the final list of integrations.

Principles

  • You approve sensitive actions

    The design requires your explicit approval before anything changes files or acts on a connected service.

  • Honest status

    We label everything as working, in development, planned or exploring. Nothing on this site is a launch promise.

  • Works with your AI tools

    It is designed to sit alongside Claude Code, Cursor and similar tools, not to replace them.

  • Credentials stay server-side

    The architecture keeps service credentials encrypted on a backend, never inside the desktop app.

How it is being built

The planned product is a desktop app built with Electron, React and TypeScript, with a separate Node.js backend. Connections to other services go through that backend, which stores their credentials encrypted, so the desktop app never holds them. Each service connects through its own adapter and starts with read-only access.

The project does not run or bill for its own AI model today. It is designed to work alongside AI coding tools such as Claude Code and Cursor.

Who is behind it

It is an independent project in early development.

The project is called VibeHeal. Its catch line is "Just vibeheal it."
