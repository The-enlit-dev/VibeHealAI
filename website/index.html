The problem

Building with AI is fast. Everything around it isn't.

  • Code you didn't write

    AI tools change files you don't fully understand, and it is hard to tell which change matters.

  • Errors without a map

    When a project breaks, the error message rarely tells a beginner where to start.

  • Tools in ten tabs

    Code, hosting, database, design and chat each live somewhere else, with their own dashboards.

  • Chores that eat build time

    Running checks, keeping track of what changed and repeating the same steps add up.

Capabilities

What it's designed to do

    Planned

    Look at your project's setup and explain errors in plain language, so you know where a problem comes from.

  • Code safety and recovery

How it works

How it's intended to work

An outline of the planned workflow. Details may change before release.

  1. 01

    Connect your project and tools

    Choose a project folder and, if you want, connect services you already use. Connections start read-only.

  2. 02

    Understand what's happening

    See your project's setup, recent changes and errors explained in plain language.

  3. 03

    Automate the repetitive parts

    Pick the tasks to automate and when they run. You approve anything that changes files or services.

  4. 04

    Stay in control

    Review every change, keep backups and undo what you don't want. Your own AI tool does the coding.

Principles

Built around staying in control

  • You approve sensitive actions

    The design requires your explicit approval before anything changes files or acts on a connected service.

  • Honest status

    We label everything as working, in development, planned or exploring. Nothing on this site is a launch promise.

  • Works with your AI tools

    It is designed to sit alongside Claude Code, Cursor and similar tools, not to replace them.

  • Credentials stay server-side

    The architecture keeps service credentials encrypted on a backend, never inside the desktop app.

Common questions

What is this project?

It is a planned AI assistant for vibe coders: people who build apps, websites and software with AI tools.

It aims to help with the wider workflow around AI-assisted coding: understanding a project, debugging errors, connecting the tools you already use, automating repetitive tasks and recovering safely when a change breaks something.

Code safety and recovery is one feature, not the whole product. The project is in early development and is not available to use yet.

Vibe coders first, especially beginners, and then indie hackers and independent developers.
